把你要听的音乐文件放在这个文件夹里
====================================

▍一句话版本

    文件名和曲名对得上，放进来就生效 —— 什么都不用改。

        Echoes.mp3    →  点「播放」就有声音


一、放哪儿？两种摆法都认
------------------------

① 平铺（歌少的时候最省事）

    assets/audio/
    ├── Echoes.mp3
    ├── Forest Walk.mp3
    └── ……

② 按分类分文件夹（歌多了以后好找，推荐）

    assets/audio/
    ├── 氛围/
    │   └── Echoes.mp3
    ├── 民谣/
    │   ├── Far From Home.mp3
    │   └── Old Old Love.mp3
    └── 轻音乐/
        ├── Forest Walk.mp3
        └── The Long Road.mp3

    程序会先找平铺的、再找分类文件夹里的，先找到哪个用哪个。

    文件夹叫什么名字你随意 —— 按歌手建（梁博/、花粥/、毛不易/…）
    一样能认出来。分类是每张碟「✎」里填的那栏「分类」，
    碟架就是按它分组的；文件夹名跟分类一样的话，找起来最顺手。

③ 想用完全不同的文件名 / 路径？

    点那张碟右上角的「✎」，把「本地音频」改成你实际的路径就行，
    例如 assets/audio/我的收藏/sunset.mp3。


二、后缀不挑（但推荐 mp3）
--------------------------

    支持这些后缀，按顺序试：mp3 → m4a → ogg → wav → flac → aac → opus

    配置里写的是 .mp3，你实际放 Echoes.m4a / Echoes.ogg
    都找得到 —— 程序会挨个试，先命中哪个用哪个。

    mp3 排第一是有原因的：体积小，所有浏览器都认。
    flac 音质好但个别浏览器放不出来，能用 mp3 就用 mp3。

    找到的文件和配置里写的不一样时，唱片机下面会直接告诉你
    实际用的是哪个文件（连它在哪个子文件夹里一起说）。


三、放好以后
------------

    刷新浏览器：

    · 每张碟下面会从「待放文件」变成绿色的「本地有声」
    · 唱片机下面会显示实际用的是哪个文件
    · 点「播放」就有声音了

    文件时长也会自动按文件里的真实时长显示，覆盖配置里写的那个。


四、⚠ 从音乐软件下载的文件，多半放不出来
----------------------------------------

    这是最容易踩的坑。各大平台的「付费下载」给的不是普通音频，
    而是加密文件，只有它自家的播放器能解：

        QQ音乐      .mgg  .mflac  .mflac0  .qmc0  .qmcflac  .qmcogg
        网易云音乐  .ncm
        酷狗        .kgm  .vpr
        酷我        .kwm

    这些文件**放进本站也不会响** —— 不是路径写错了，是浏览器根本读不懂，
    得先用别的方式拿到普通格式（mp3 / m4a / ogg / wav）才行。

    本站不会、也不应该去破解它们的加密，请通过正规途径获取文件：
    用自己买的 CD 转、买数字专辑、或者用平台允许的下载方式。


五、关于版权
------------

    碟架现在登记的六首（Echoes / Far From Home / Fifth of February /
    Forest Walk / Old Old Love / The Long Road）是免版权曲库的曲子，
    可自由用于个人网站。想换成自己喜欢的歌：把文件按上面的方式放进本
    文件夹，再到首页碟架每张碟的「✎」里改歌名 / 歌手 / 本地音频路径。

    注意别放从音乐软件下载的加密文件（见第四节），也别把有版权的
    商业歌曲文件放进公开仓库 —— 网站部署到 GitHub Pages 后文件是公开的。
