为什么现在是空的
----------------
整套试卷图片大约 77MB。个人站是要发到 GitHub Pages 的，
塞 77MB 图片进去既慢又占仓库，所以打包时故意没带。

想在本机看完整的试卷图片
------------------------
1. 找到原来那份目录（桌面 → xiaoli → 专升本 → c语言 → c语言学习网站 → assets → papers）
2. 把整个 papers 文件夹拷到这个目录下面，变成 c/assets/papers/
3. 刷新 papers-image.html

代码一行都不用改 —— 图片路径本来就是这么写的。
图片不在的时候，页面会显示一块「图片未随仓库打包」的占位说明，不会碎一地。
